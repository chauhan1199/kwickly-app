# Project Workflow Rule

For every phase of development or refactoring in this repository, agents must follow this disciplined cycle:

1. **Analyze** -> Understand the code and document findings.
2. **Identify** -> List bugs, incomplete flows, and design issues.
3. **Fix** -> Implement production-ready changes.
4. **Verify** -> Confirm builds, tests, and workflows still work.
5. **Document** -> Record what changed, why it changed, and how it was validated.

This disciplined loop helps prevent regressions and keeps the repository stable while progressively improving its quality.
