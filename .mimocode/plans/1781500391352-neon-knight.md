## Part 3: Create Shared Config

Create `mobile/src/config/index.js`:
```js
import { Platform } from 'react-native';

const DEV_API = 'http://10.0.2.2:5000/api/v1';
const PROD_API = 'https://api.kwickly.com/api/v1';

const DEV_SOCKET = 'http://10.0.2.2:5000';
const PROD_SOCKET = 'https://api.kwickly.com';

const isDev = __DEV__;

export default {
  API_URL: isDev ? DEV_API : PROD_API,
  SOCKET_URL: isDev ? DEV_SOCKET : PROD_SOCKET,
  UPLOADS_URL: isDev ? 'http://10.0.2.2:5000' : 'https://api.kwickly.com',
};
```

Then replace all `http://10.0.2.2:5000` references with `Config.UPLOADS_URL`.
